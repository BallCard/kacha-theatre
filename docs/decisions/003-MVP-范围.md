# ADR-003: MVP 范围 — 从连载叙事降级为单图体验

**日期**：2026-05-23
**状态**：✅ 已决（v2 单图） → **已被 [ADR-004](./004-Part2-剧情游戏增量.md) 扩展为 v2.1（Part 1 + Part 2）**
**决策者**：队长

> ⚠️ **后续修订（2026-05-23 凌晨）**：本 ADR 锁定的是 Part 1（单图打分 + 海报二创）范围，**保持有效不变**。
> Part 2（5 节点互动剧情）作为纯增量补充，详见 [ADR-004](./004-Part2-剧情游戏增量.md)。

## 背景

5.23 头脑风暴过程中，方案经历了一次大幅迭代：

1. **v1（5.22 晚）**：单图拍照 → AI 自动出报告 + 自动盖贴纸 → 导出。带 P1 摸鱼榜（强制盖脸 + 排名）
2. **v1.5（5.23 早，曾设想）**：5-6 张照片编织"平行世界连载叙事"，AI 锁定主角人设、章章呼应前文。详见对话记录
3. **v2（最终 MVP，本 ADR）**：回到单图模式，但加深两条体验线——6 档段位称号系统 + 修图式二创编辑层

## 决策

**MVP 范围锁定为 v2：**

- ✅ 单图上传 → AI 输出 [评分 + 段位 + 3 个候选称号 + 玄学奏折]
- ✅ 6 档段位系统（打工新丁 → 假寐天尊），各档独立配色 + 印章样式
- ✅ 修图二创：18 张贴纸库 + 自定义文字气泡 + 一键切换称号
- ✅ 导出竖版长图

**降级到 P1+**：
- 连载叙事（5-6 张照片编织平行世界）
- 摸鱼榜（单图榜 + 卷宗榜）
- 多宇宙换皮（武侠 / 西游 / 赛博朋克）

**永远不做**：
- 人脸识别比对（隐私雷区）
- 登录账号 / 数据库
- AI 重绘魔改

## 理由

### 为什么放弃连载叙事

虽然连载叙事在头脑风暴时讨论得很完整，但 25h 黑客松场景下：

1. **演示难度高**：评审现场需要拍完 5-6 张才走完闭环，每张 VLM 延迟 8-10s，整段 demo 时间 60-90s，节奏拖沓
2. **工程量翻倍**：6 次 VLM 调用 + 上下文管理 + 主角人设卡 + 终章总览，相对 P0 工时翻 1.5×
3. **MVP 价值已足够**：单图 + 段位 + 二创已经能完整覆盖赛道四 5 个评审维度，无需为"叙事弧"额外冒险

### 为什么不退回 v1 原状

v1 缺少两个差异化点，仅做 v1 在赛道四"AI 能力与产品结合 30%"维度容易显得平庸：

1. **段位系统**让 `moyu_index` 从一个装饰数字升级为"社交段位货币"，同事之间能比"谁段位高"，社交传播性强
2. **修图式二创**让用户从"被动消费 AI 出图"变成"主动参与创作"，符合用户的需求（"贴纸有库供用户拖拽"），评审话术可以打"AI 起势，用户加彩"

### 关键设计取舍

| 取舍 | 选择 | 原因 |
|---|---|---|
| AI 是否自动盖贴纸 | **不自动** | 用户的"二创自由"是 MVP 第二个加厚点；AI 只出文案 / 评分 / 称号，不抢戏 |
| 称号"层次"含义 | **AI 评分映射 6 档** | 段位感强、社交可比；用户的明确意图 |
| 自定义输入称号 | **砍掉** | 脏字风险，且用户没强调 |
| `title_candidates` 来源 | **AI 现抽** | 同分不同图称号不同，更搞怪；不预制词库 |

## 后果

- **优势**：MVP 范围清晰、工程量回到原 P0 + 15h 增量，预算内。设计文档（[2026-05-23-摸鱼御史-design.md](../superpowers/specs/2026-05-23-摸鱼御史-design.md)）从 619 行收紧到 ~400 行
- **代价**：连载叙事的"惊艳感"先让位给 MVP 完成度。若 5.24 凌晨 1:00 主闭环跑通且有富余时间，可考虑加 P1 摸鱼榜
