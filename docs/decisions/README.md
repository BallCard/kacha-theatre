## 决策模板

每个决策记录应包含：

1. **背景**：为什么需要做这个决策
2. **选项**：考虑了哪些方案
3. **决策**：最终选择了什么
4. **理由**：为什么选这个（权衡了什么）
5. **后果**：这个决策带来的影响（正面+负面）
6. **执行人**：谁负责落地

## 使用说明

- 重大决策（影响整体方向、技术架构、用户体验）必须记录
- 小决策（局部实现细节）可选记录
- 决策可以被推翻，但要记录新的 ADR 说明为什么改变
