# ADR-002: 技术栈选择

**日期**：2026-05-23
**状态**：✅ 已决
**决策者**：队长 + 技术负责人

## 背景

25 小时极限开发，需要选择能快速出原型且降低演示翻车风险的技术栈。

## 考虑因素

1. **团队熟悉度**：优先用熟悉的技术
2. **开发速度**：能快速搭建可演示原型
3. **AI 集成**：方便接入 VLM
4. **演示稳定**：移动端 H5 + 现场断网兜底

## 技术选型

### 前端

**决策**：Vue 3 + Vite + TypeScript + TailwindCSS + Konva.js + html-to-image

**理由**：
- Vue 3 + Vite：开发速度快，HMR 体验好
- TypeScript：mock 数据 + 接口契约有类型保障，减少联调返工
- TailwindCSS：不引入 UI 库，自己写组件保持小程序简洁风
- **Konva.js**：贴纸拖拽 / 缩放 / 旋转手势全封装好。本次 MVP 的"修图式编辑层"是 P0 重点，避免自造轮子
- html-to-image：导出长图，备选 html2canvas

**放弃 React 的原因**：团队 Vue 更熟，开发速度优先。
**放弃 Next.js / Nuxt 的原因**：不需要 SSR，纯静态 SPA 部署最快。

### 后端

**决策**：Node.js BFF（Express 或 Vercel Serverless Function）

**理由**：
- 只做一件事：包一层 prompt + 把 API key 藏起来 + JSON schema 校验
- 不做业务逻辑、不存图、不上数据库
- Vercel Serverless 与前端一起 push 即部署，零运维

**放弃 FastAPI / Flask 的原因**：Python 后端虽然 AI 友好，但本次后端逻辑极简，Node 与前端栈统一即可。

### AI 能力

**决策**：豆包 vision-pro（备选 GPT-4o）

**理由**：
- **中文调性最贴近"玄学御史"语料**，prompt 工程更稳
- 字节生态，与抖音赛事政治正确（评审加分）
- token 成本最低，25h 内可无脑刷
- JSON 输出稳定性可控

**备选切换条件**：第 6h 联调时若豆包 JSON 飘到不可救药，前端调用层留 `provider` 字段抽象，无缝切到 GPT-4o。

### 部署方案

**决策**：Vercel（前端 + 后端 Serverless）+ 笔记本本地 backup server

**理由**：
- Vercel：push 即部署、自动 HTTPS、免运维
- 本地 backup：现场断网时切到笔记本热点 + 本地 server，作为线上挂掉的最后一道兜底

### 演示兜底

**决策**：URL 加 `?offline=1` 走纯前端模式，所有 `/analyze` 直接返回预录 JSON

- 5.24 凌晨 1:00 前必须预备 3 张样例图（30 / 65 / 95+ 分数段各一）+ 配套手工调过的 JSON
- 现场 demo 先走 offline 模式确保稳，再补一段"真拍一张"突出 AI 实时能力

## 风险

| 风险 | 概率 | 对策 |
|---|---|---|
| VLM 评分飘、等级不一致 | 中 | schema 校验 + 后端按 score 强制覆盖 tier |
| VLM JSON 不合法 | 中 | retry 1 次 + 兜底模板（§6.5） |
| VLM 延迟 > 10s | 中 | 8s 切等待动画 + 趣味文案，超 15s 报错 |
| iOS Safari 导出失败 | 中 | 长按保存 + Web Share API 双路径 |
| 现场网络炸 | 高 | offline 模式 + 本地 backup server |

## 变更记录(Amendment · 2026-05-23 晚)

实际开发与原决策有偏差,以下为**当前真实状态**(原决策记录保留作历史)。

| 项 | 原决策 | 实际 | 偏差原因 |
|---|---|---|---|
| 前端框架 | Vue 3 | **React 19** | Gemini 一键产出前端工程时选了 React 模板,联调没问题就没回切 |
| VLM 主模型 | 豆包 vision-pro | **`gemini-2.5-flash-nothinking`** | 改用 OpenAI 兼容中转网关,统一接入多模型,豆包没用上 |
| VLM 兜底 | GPT-4o | **`gpt-4.1-mini`** | 同上,中转网关里 4.1-mini 更便宜稳定 |
| 调用协议 | 豆包原生 SDK | **OpenAI 兼容协议**(`OPENAI_API_KEY` + `OPENAI_BASE_URL`) | 一套协议接所有模型,切模型只改环境变量 |
| BFF | Node BFF | **Vercel Functions**(`server/api/*.ts`) | 直接用 Vercel serverless,免运维 |

**保留正确的决策**: TailwindCSS、Konva.js、html-to-image、demo 短路降级策略全部按 ADR 原计划落地。
