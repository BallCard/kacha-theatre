# ADR-007 · Part 2 v2 重做与示例缓存

**日期**：2026-05-24
**状态**：已实施

## 背景

新需求文档把 Part 2 从"古风 5 节点宜忌剧"改为"咔嚓入梦 + 三幕选择树（1+3+9+27=40 节点）+ 五主题三画风"。和旧实现差异过大，旧字段（宜忌 / 时辰 / 段位驱动结局）无法复用。

同时要求：
- Part 1 / Part 2 都基于图片内容哈希做磁盘缓存
- 选定示例做满 40 节点全量缓存，演示秒回
- 网页中央手机壳，移动端自适应全屏
- 剧情模型可切 claude-sonnet-4-6 / gpt-5；图模型固定 gpt-image-2

## 决策

### 1. 直接替换 React Part 2，不增量改

**为什么不增量**：结构（节点数、入口流程、主题维度、画风选择）几乎所有维度都不一样，强行兼容只会引入两套字段、两套状态机，代码可读性更差。旧古风 5 节点版本作为 ADR-004 时代的产物归档。

**保留**：`ComicStripExport`（长图导出思路通用，重写了 props 即可），其它旧文件全删。

### 2. 主题 × 画风的二维选择

主题（剧情走向）：宫斗剧 / 穿越重生 / 悬疑探案 / 打脸 / 爽文
画风（视觉关键词）：恋与深空 / 蓝色监狱 / 仙逆

实现上：
- 主题通过 `THEME_TONE` 注入到 LLM 系统提示词，影响叙事口吻
- 画风通过 `ART_STYLE_PROMPTS` 拼接到 imagePrompt 头部，统一视觉骨架
- 这套二维矩阵的好处：每条组合都有独立的缓存键，演示时可以预热多组对比，主题与画风正交。

### 3. A 翻身 10% 概率放后端 roll

**为什么不让 LLM 决定**：实测概率不可控，LLM 倾向于给"我"压倒性结局。让后端在终幕节点 `Math.random() < A_WINS_RATE` 决定 `endingMode`，再把指令喂给 LLM 让它按要求写"我赢"或"A 翻身"结局。比例靠环境变量 `A_WINS_RATE` 调（默认 0.10）。

### 4. 缓存版本号策略

- 缓存根目录：`server/data/cache/<CACHE_VERSION>/<namespace>/<imageHash>/<scopeKey>.json|.png`
- `CACHE_VERSION` 常量集中在 `server/lib/cache.ts`
- prompt / schema / 镜头池 / 画风字典调整后 → bump `CACHE_VERSION`（旧缓存自然失效；不删旧目录避免误伤同事在跑的演示）
- 演示前可手动 `rm -rf server/data/cache/v1/` 重灌

### 5. 缓存范围分两档

- **示例（演示用）**：开发者在 `server/data/story-examples.json` 配置 `{imagePath, theme, artStyle}`，跑 `npm run warmup-story` 把这条组合的 40 个节点全灌满（含 27 终幕）。演示时无论观众选哪条路径都秒回。
- **普通用户**：按需走 LLM + gpt-image-2 实时生成；同时写入缓存，下次同 `(imageHash, theme, artStyle, pathKey)` 命中。

### 6. 图像生成搬到后端

旧版前端直连 OpenAI（VITE_OPENAI_API_KEY 暴露在浏览器）。Part 2 v2 把图生图集中到 `server/lib/imageGen.ts`，避免 key 泄漏，也让缓存能放在服务器盘上。前端只接 `/api/plot/v2/node` 一个接口。

### 7. 镜头多样性硬约束

需求要求每幕镜头/动作/角度不同。实现：
- 后端维护 `SHOT_POOL`（12 种镜头描述）
- 生成新节点前从池里选一个，排除该路径祖先已用过的镜头
- 把镜头关键词注入用户提示词 + 最终 imagePrompt 末尾，保证既影响 LLM 的描述，又直接喂给 gpt-image-2
- 缓存里持久化 `shotUsed`，重玩走相同路径时镜头一致

## 影响

- `/plot/next`、`/plot/ending` 接口废弃（之前未发布到生产，无破坏）。
- 旧 React Part 2 完全移除，少了约 1700 行老代码。
- 古风原型新增「入梦 · 演绎剧情 →」按钮，通过 localStorage 把图传给 React Part 2。
- 新增依赖：无（沿用已有 undici / ajv / html-to-image）。

## 风险

- 同一张图哈希 16 位短截，理论碰撞概率极低但不为零；如出问题改 32 位。
- gpt-image-2 偶尔不复刻人脸（参考图机制不稳），可通过加强 prompt + 后续补 face-swap 缓解，本轮先观察。
- 中转网关是否同时接 claude-sonnet-4-6 与 gpt-5 取决于 `OPENAI_BASE_URL` 配置，调用失败会回退到 `gpt-4o-mini`。
