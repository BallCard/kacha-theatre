# ADR-001: 赛道选择

**日期**：2026-05-23  
**状态**：待定  
**决策者**：全队讨论

## 背景

比赛提供两个赛道：
- **赛道二**：抖音精选-内容重构（用户价值感30%）
- **赛道四**：视觉搜索（AI能力与产品结合30%）

需要在赛题详细要求发布后（10:00）快速选择赛道。

## 选项

### 选项A：赛道二 - 内容重构

**优势**：
- 用户价值感权重高（30%），容易打动评委
- 场景更具体，容易找到真实痛点
- 参考作品"随厨小食堂"提供了清晰方向

**劣势**：
- 需要深入理解视频内容结构化
- 内容重构的创新点不好找

**适合场景**：
- 团队有视频处理经验
- 能快速找到有价值的内容场景
- 擅长用户体验设计

### 选项B：赛道四 - 视觉搜索

**优势**：
- AI能力权重高（30%），技术驱动
- 视觉+语音多模态，技术挑战性强
- 创新空间大

**劣势**：
- 需要完整的用户旅程设计
- 技术复杂度高，25小时内风险大

**适合场景**：
- 团队有多模态AI经验
- 能构建完整交互流程
- 技术实力强
