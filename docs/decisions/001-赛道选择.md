# ADR-001: 赛道选择

**日期**：2026-05-23
**状态**：✅ 已决
**决策者**：队长 + 全队

## 背景

比赛提供两个赛道：
- **赛道二**：抖音精选-内容重构（用户价值感 30%）
- **赛道四**：视觉搜索（AI 能力与产品结合 30%）

## 决策

**选择赛道四 · 视觉搜索**

## 理由

1. **AI 能力权重最高（30%）与产品契合**：摸鱼御史方案的核心是 VLM 一次往返同时输出"评分 + 段位映射 + 多候选称号 + 玄学奏折"，AI 不只是识图，而是"评分员 + 编剧"。这正好对应赛道四"讲清楚技术如何支撑体验展开"的评审锚点。
2. **真实场景天然存在**：办公室摸鱼是高频、自然、用户能即拍即用的视觉触发场景，符合"贴近日常使用路径"的评审标准。
3. **闭环可在 25h 内做完**：单图上传 → AI 审阅 → 修图二创 → 导出长图，环节清晰、技术风险可控。
4. **延展空间清晰**：同一套架构可扩展到自拍 / 宠物 / 视频抽帧，赛后有产品化空间。

## 放弃赛道二的原因

- 赛道二评审重点"用户价值感 30%"虽高，但"内容重构"对视频结构化解析要求高，25h 内做出有说服力的体验难度大。
- 参考作品"随厨小食堂"门槛已经被拉高，同类做法难以超越。

## 后果

- **优势**：评审标准与我们方案天然对齐，AI 能力是亮点而非堆料。
- **风险**：VLM 输出稳定性是命门。对策：schema 校验 + retry 1 次 + 兜底模板（详见 [设计文档 §6.5](../superpowers/specs/2026-05-23-摸鱼御史-design.md)）。

## 执行落地

- ✅ 已对齐赛道，方案设计、prompt 工程、演示话术均围绕赛道四评审锚点
- ✅ 90s pitch 脚本中"AI 能力差异化"段落明确强调"AI 是编剧不是辅助"（[设计文档 §10](../superpowers/specs/2026-05-23-摸鱼御史-design.md)）
