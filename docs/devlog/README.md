## 日志模板

```markdown
# [日期] [时间段]

## 本阶段目标

- [ ] 目标1
- [ ] 目标2

## 完成事项

- [x] 完成的任务1
- [x] 完成的任务2

## 技术亮点

### [功能/模块名称]
- 实现方式
- 关键代码/思路
- 效果

## 遇到的问题

### 问题1：[简短描述]
**现象**：[详细描述]  
**原因**：[根因分析]  
**解决方案**：[如何解决的]  
**耗时**：[花了多久]  
**经验**：[下次怎么避免]

## 待办事项

- [ ] 下一步任务1 - 负责人
- [ ] 下一步任务2 - 负责人

## 风险提示

- 风险1：[描述] - 应对方案
- 风险2：[描述] - 应对方案

## 团队状态

- 士气：😊/😐/😞
- 进度：超前/正常/落后
- 需要支持：[列出需要的帮助]
```

## 使用建议

- **每4-6小时更新一次**（上午、下午、晚上、深夜）
- **重点记录**：技术难点、创新点、踩过的坑
- **简洁为主**：不要写流水账，抓关键信息
- **及时记录**：趁热打铁，不要事后补
