## AI 选印规则（guofeng 版）

| 条件 | 第 1 枚 | 第 2 枚 |
|---|---|---|
| score ≥ 80 | 神游太虚 | 大吉 / 神游太虚 / 准奏（按 pose 微调） |
| 55–79 | 摸鱼有理 | 同上 |
| 30–54 | 奉天承运 | 同上 |
| < 30 | 驳回 | 同上 |
| pose 含睡/趴/瘫 或 yi 含神游 | — | 神游太虚 |
| ji 含会议/汇报/急/催 | — | 驳回（讽刺） |
| 否则 score ≥ 70 | — | 大吉 |

锚点候选：左上 / 右中 / 左中 / 右下，按"远离硬占位 + 远离人脸 + 互相不挤"挑前 2 个。
