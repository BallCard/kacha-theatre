### 优化迭代（同日）

实测单节点 ~120s（gpt-image-2 是主瓶颈），三件优化：

1. **服务端推测预热**：节点完成后 `setImmediate` fire-and-forget 3 个子节点；不递归避免雪崩；`STORY_PREFETCH=0` 可关
2. **in-flight 去重**：同 cache key 并发请求共享 Promise，防止 prefetch 与用户主请求双烧
3. **图改 1024×1024**：替代竖图，省 30-40% 出图时间；`STORY_IMAGE_SIZE` 可改

前端 StoryV2Screen 也加了「intake 选完风格 500ms 后静默触发 root 预热」。提升有限（窗口 5-10s）但代码 10 行。

### 实测延迟

| 场景 | 耗时 |
|---|---|
| 冷启动 root | ~120s |
| 缓存命中 | ~12ms |
| 紧接着点 A（prefetch 没跑完→in-flight 去重共享同一生成） | ~157s |

结论：演示场景必须用 `npm run warmup-story` 提前灌满示例。
