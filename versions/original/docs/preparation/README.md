## 💡 核心理念（牢记）

> **执行力和找到谈得来的伙伴最重要，点子是其次**

### 开发原则
- ✅ **80分能演示 > 95分半成品**
- ✅ **快速原型优先，不追求完美**
- ✅ **AI 能力要突出，改变内容使用方式**
- ✅ **场景真实，用户价值清晰**

### 功能取舍
- 设计阶段：砍掉 70% 功能
- 开发中期：再砍 50%
- 演示时：只展示核心功能

### 时间分配（25小时）
- 前3小时：需求与设计（含砍功能）
- 中间12小时：核心功能开发
- 后5小时：体验优化
- 最后3小时：演示准备
- 预留2小时：缓冲
