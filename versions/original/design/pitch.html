§1为什么是这个

真实场景
下午 3 点

对面同事头一歪睡过去了。你想发群里玩梗，但配文懒得想 —— 这就是日常被忽略、又每天都发生的视觉触发时刻。

目标用户
20–35 白领

熟抖音梗文化、有自我嘲讽 + 群聊玩梗刚需。摸鱼是社交货币，不是负面词。

记忆锚点
妙鸭 × 抽签机

妙鸭让一张脸变 AI 写真，但要训练、要付费、社交链断在导出那一步。我们要的是 30 秒零门槛、能直接甩进群聊的那一份。

§3AI 不是辅助，AI 是导演

不是"识别完贴个标签"那种工具型 AI。一次 VLM 调用同时承担四件事，token 开销可控、效果集中：

视觉理解
姿态 + 物体 + 人脸坐标

7 种姿态分类 + 桌面线索（咖啡/键盘/文件）+ 归一化人脸框，作为玄学素材 + 强制盖印依据。

内容生成
御史奏折口吻

封号、玄学解读、今日宜忌 —— 固定 prompt 模板 + few-shot 保证调性统一。

视觉重构
贴纸坐标驱动 Canvas

VLM 直接吐 JSON 坐标，前端按坐标自动盖戳。AI 真的在"动手改图"。

用户再创作
可拖拽微调

不准的位置用户能拖；好玩的贴纸可以加。AI 是搭子，不是上帝。

§5Prompt 工程 · 调性命门

整套产品调性挂在这份 prompt 上。VLM 一次往返同时输出结构化 JSON，schema 校验 + retry + 兜底模板三重保险。

System Prompt（御史人设）

# 你是御史房派驻现代办公室的明代御史台官员
语气：半文半白、玄学占卜、互联网梗
工作：观察办公室照片，输出一份「御史奏折」+ 在图上盖戳的建议位置

输出原则：
1. 摸鱼是社交货币，嘲讽但不刻薄，不羞辱当事人
2. 不评价相貌、体型、性别、肤色；只描述姿态与桌面物件
3. 不识别真实身份；只用"该员"、"卿"等代称
4. 严格按 JSON schema 输出，不要 markdown 代码块包裹
5. 如果图中没有人，仍按"无人值守"主题生成奏折

隐私底线（不可妥协）

  • VLM 同时返回 face_boxes，前端用大号"御史印"PNG 自动盖人脸
  • 用户不能跳过这一步，但可拖动御史印位置
  • 上榜按钮文案：「匿名摸鱼，互不揭穿 · 提交即同意脸部已被遮蔽」
  • 无账号体系 · 无数据库 · 仅当日内存 + JSON 文件
  • 每张榜单图带 ⚠️ 举报 按钮，点即下架（不走审核）
