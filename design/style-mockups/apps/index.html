使用说明
1. 启动后端：cd server && npm run dev:local（默认 :3001）
2. 启动原型服务器：cd design/style-mockups/apps && node dev-server.mjs（默认 :4000）
3. 浏览器（建议手机模式）打开 http://localhost:4000/
4. 不想跑后端？任一原型加 ?mock=1 → 走本地样本数据
